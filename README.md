#  Telegram Automation Bot with n8n


نظام أتمتة متكامل لبوت تليجرام باستخدام منصة n8n. يقوم المشروع باستقبال رسائل المستخدمين فورياً وإرسال الردود الآلية دون أي تدخل بشري.

---

## ✨ المميزات الرئيسية (Key Features)

* ⚡ استجابة فورية: استقبال الرسائل لحظياً باستخدام الـ Webhooks.
* 🔄 سير عمل آلي: معالجة الإدخالات وإرسال الردود التلقائية بسرعة.
* 🛠️ سهولة التعديل: إمكانية إضافة وظائف جديدة أو ربطها بقواعد بيانات بسهولة.
* 🛡️ أمان كامل: فصل البيانات الحساسة ومفاتيح الـ API تماماً عن الكود.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* [n8n](https://n8n.io/) - منصة أتمتة سير العمل (Workflow Automation).
* [Telegram Bot API](https://core.telegram.org/bots/api) - للربط والتفاعل مع تطبيق تليجرام.

---

## 🚀 طريقة التشغيل (How to Use)

1. تحميل الملف: حمّل ملف الـ .json المرفق في هذا المستودع.
2. استيراد الـ Workflow:
   * افتح واجهة n8n.
   * اختر Workflows ثم اضغط على Import from File.
3. إعداد البوت:
   * أنشئ بوت جديد عبر [@BotFather](https://t.me/BotFather) واحصل على الـ Bot Token.
   * اضغط على عقدة التليجرام داخل n8n وأضف الـ Token في قسم الـ Credentials.
4. التفعيل: قم بتغيير حالة الـ Workflow إلى Active.

---
